# Sky — คืนนี้มีอะไรให้ค้นพบ

เว็บแอพดูดาวภาษาไทย สร้างด้วย React และ Vite รองรับหน้าจอคอมพิวเตอร์และมือถือ

## เริ่มใช้งาน

ใช้ Node.js 22.12 ขึ้นไป (ทดสอบบน Node.js 24)

```sh
cd /workspace/Sky
npm ci
npm run dev
```

ไม่ต้องมี API key หรือบริการฐานข้อมูล ข้อมูลดาวและฟอนต์อยู่ในแอพทั้งหมด

Vite ตั้งค่า `base: '/Sky/'` สำหรับ GitHub Pages ของ repository นี้ เปิด dev server ที่เส้นทาง `/Sky/` ไฟล์ข้อมูลและลิงก์สัญญาอนุญาตใช้ `import.meta.env.BASE_URL` เพื่อโหลดจากเส้นทางเดียวกัน หากกำหนด `SKY_TEST_URL` ให้ระบุ URL เต็มที่ลงท้ายด้วย `/Sky/` เช่น `http://127.0.0.1:4173/Sky/`

## เผยแพร่ผ่าน GitHub Pages

1. ใน repository `chalee2000/Sky` ไปที่ **Settings → Pages → Build and deployment → Source** แล้วเลือก **GitHub Actions**
2. Workflow `.github/workflows/deploy-pages.yml` จะติดตั้ง dependencies ตาม lockfile ทดสอบ build และ deploy `dist/` ทุกครั้งที่ push ขึ้น `main`
3. เรียก deploy เองได้ที่ **Actions → Deploy Sky to GitHub Pages → Run workflow** โดยเลือก branch `main` หาก push แรกเกิดก่อนเปิด Pages ให้รัน workflow อีกครั้งหลังตั้งค่า
4. เมื่อขั้นตอน deploy สำเร็จ เปิดแอพได้ที่ **https://chalee2000.github.io/Sky/**

Workflow ใช้ Node.js 24 และ `GITHUB_TOKEN` ที่ GitHub จัดให้โดยอัตโนมัติ ไม่ต้องเพิ่ม secret เอง Repository ต้องเปิดใช้ GitHub Actions และรองรับ GitHub Pages ตามสิทธิ์บัญชี

## สิ่งที่ทำได้

- แผนที่ดาวจริง 5,044 ดวง คำนวณจากวันเวลาและพิกัดผู้สังเกต
- ข้อมูลดาวเด่น 78 ดวง และกลุ่มดาว 22 กลุ่ม พร้อมเส้นกลุ่มดาวบางส่วน
- เลือกเมือง ใช้ Geolocation หรือกรอกละติจูด/ลองจิจูด
- เลือกวันและเวลา เลื่อนเวลา หมุนแผนที่ และซูม
- โหมดส่องฟ้าตามทิศและการเอียงมือถือ พร้อมขออนุญาตเซ็นเซอร์บน iPhone
- ค้นหาด้วยชื่อภาษาไทย/อังกฤษ บันทึกดาวไว้ใน localStorage
- เฟสดวงจันทร์โดยประมาณ แจ้งช่วงกลางวัน/สนธยา และโหมดลดความสว่าง

เวลาทั้งหมดใช้ UTC+7 แม้จะเลือกเมืองนอกประเทศไทย แผนที่เป็นมุมมองเมื่อเงยหน้าขึ้นฟ้า จึงแสดงทิศตะวันออกทางซ้าย ตำแหน่งผู้ใช้ใช้คำนวณภายในเบราว์เซอร์เท่านั้น การขอ Geolocation ต้องใช้ HTTPS หรือ localhost และการอนุญาตจากผู้ใช้

## ส่องฟ้าตามมือถือ

1. เปิดเว็บไซต์ HTTPS ใน Safari บน iPhone หรือ Chrome บน Android
2. เลือกตำแหน่งปัจจุบันหรือเมืองที่ตรงกับที่อยู่จริง เช่น ชุมพร
3. กด **ส่องฟ้าตามมือถือ** และอนุญาตการเคลื่อนไหวและทิศทางหากเบราว์เซอร์ถาม
4. ชี้ด้านกล้องหลังไปยังท้องฟ้า แผนที่จะเปลี่ยนช่องมองตามทิศ การเงย และการหมุนหน้าจอ โดยใช้เวลาปัจจุบัน
5. กด **หยุดส่องฟ้า** เพื่อกลับไปลากดูแผนที่และเลือกเวลาเอง

โหมดนี้เป็นแผนที่ท้องฟ้าจำลอง ไม่เปิดกล้องหรือแสดงภาพจากกล้อง ไม่มีการส่งข้อมูลเซ็นเซอร์ออกจากอุปกรณ์ มุมมองส่องฟ้ามีทิศตะวันออกอยู่ทางขวาเมื่อหันหน้าไปเหนือ ต่างจากแผนที่ทั้งท้องฟ้าที่ถือเหนือศีรษะ

รองรับ `webkitCompassHeading` บน iPhone และข้อมูล absolute orientation บน Android ข้อมูลการหมุนแบบ relative อย่างเดียวจะไม่ถูกใช้แทนทิศเหนือ หากไม่อนุญาต ไม่รองรับ หรือไม่ได้รับข้อมูล แอพแจ้งสาเหตุและกลับไปใช้แผนที่ปกติ เข็มทิศอาจอ้างอิงทิศเหนือแม่เหล็กและคลาดเคลื่อนจากทิศเหนือจริง รวมถึงได้รับผลจากเคสแม่เหล็กและโลหะใกล้เครื่อง ลองปรับเทียบด้วยการหมุนมือถือเป็นเลข 8 ไม่เหมาะกับการชี้กล้องโทรทรรศน์อย่างแม่นยำ

## ตรวจสอบและ build

```sh
npm test
npm run build
npm run preview
```

`npm test` รันทดสอบสูตรดาราศาสตร์ 9 ข้อ และการแปลงทิศทาง/ฉายภาพเซ็นเซอร์ 9 ข้อ; production build อยู่ใน `dist/` สามารถใช้กับ static hosting ได้

ทดสอบเบราว์เซอร์ โดยเปิด dev server พอร์ต 5173 ในอีกเทอร์มินัลก่อน:

```sh
npm run dev -- --port 5173
# ในอีกเทอร์มินัล
npm run test:e2e
npm run test:sensors
```

Smoke test ใช้ Chromium ที่ `/usr/bin/chromium` กำหนด `CHROMIUM_PATH` เพื่อเปลี่ยน executable หรือ `SKY_TEST_URL` เพื่อทดสอบเซิร์ฟเวอร์อื่น ตรวจการโหลดแค็ตตาล็อก การค้นหา บันทึกหลัง reload เวลา ตำแหน่ง กลุ่มดาว การซูม การเปิดปิดเส้น หน้าต่าง วิธีรับมือกับการปฏิเสธตำแหน่ง และหน้าจอมือถือ เก็บภาพไว้ใน `test-results/`

`test:sensors` จำลอง Safari permission API, เข็มทิศ iPhone, absolute orientation บน Android, การหมุน/เอียง, การหยุดและเริ่มใหม่, การเปลี่ยนหน้า, การปฏิเสธสิทธิ์, อุปกรณ์ไม่รองรับ และกรณีไม่มีข้อมูล การทดสอบจำลองไม่ยืนยันความแม่นยำของเข็มทิศจริงบนโทรศัพท์

## แหล่งข้อมูลและความแม่นยำ

ข้อมูลดาวพื้นหลังมาจาก [d3-celestial](https://github.com/ofrohn/d3-celestial/blob/master/data/stars.6.json) โดย Olaf Frohn ภายใต้ BSD-3-Clause เก็บเป็น `[raHours, declinationDegrees, magnitude, bvColorIndex]` ใน `public/data/stars.json` พร้อม [สัญญาอนุญาต](public/data/LICENSE-d3-celestial.txt)

ตำแหน่งดาวอ้างอิง J2000 และไม่ชดเชย precession, proper motion หรือการหักเหของบรรยากาศ เหมาะสำหรับการเรียนรู้และวางแผนทั่วไป ไม่ใช่การนำทางหรือควบคุมกล้องโทรทรรศน์อย่างแม่นยำ เฟสจันทร์คำนวณจากคาบเฉลี่ยและอาจคลาดเคลื่อนประมาณหนึ่งวัน ไม่ได้แสดงตำแหน่งดวงจันทร์/ดาวเคราะห์ เมฆ แสงเมือง และสิ่งบดบังมีผลต่อการมองเห็นจริง

บันทึกดาวเก็บเฉพาะในเบราว์เซอร์ ไม่มีระบบบัญชีหรือการซิงก์ระหว่างอุปกรณ์
